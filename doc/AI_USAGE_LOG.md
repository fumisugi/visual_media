# 生成AI利用ログ

## 使用した生成AI

- OpenAI Codex
- 研究上の方針決定と結果の解釈は著者が行い、Codexは実装、集計、文書化の補助に使用した。

## 主な用途

- 著者が決定した実験設計に基づくPythonコードの実装補助
- COCOデータの抽出、YOLO-World推論、評価、可視化の実行補助
- AP/AR、bootstrap信頼区間などの集計コードとテストの作成補助
- 実験結果を反映した図表とLaTeXレポート草稿の作成補助
- 数値の整合性、PDFレイアウト、再現手順の確認補助

## 自分で修正・判断した箇所

- 対象論文としてYOLO-Worldを選定した。
- blurとprompt表現をFailure Caseとして設定し、対象カテゴリと評価条件を決定した。
- 評価画像数を100枚へ拡張し、F1だけでなくPrecision、Recall、COCO AP/AR、bootstrap信頼区間を用いる方針を決定した。
- 評価用データを手法選択に使わないよう、開発用データと評価用データを分離した。
- 各Failure Caseへ直接対応する改善を主結果とする基準を定め、効果が安定しなかった手法は採用しなかった。
- prompt prototypeとblur-aware Wiener前処理の結果を確認し、改善として主張できる範囲とLimitationsを判断した。
- 生成されたコードをローカル環境で実行し、集計値、図表、引用、レポート構成と表現を確認・修正した。
